# content/

Тексты сайта живут здесь, отдельно от вёрстки.

```
content/
  ru/
    pages/     тексты страниц (услуги, о нас, контакты)
    cases/     кейсы
    blog/      статьи
```

Причина разделения: решение по CMS отложено. Пока тексты правятся через диалог с ИИ прямо
в репозитории, но если позже понадобится админка для копирайтера, Sanity подключится
к этой структуре без переписывания страниц. Если же тексты растащить по компонентам
в `src/app/`, миграция на CMS превратится в разбор всего проекта.

Наполняется на **этапе 4**, когда переносим контент с Tilda.

Короткие строки интерфейса (кнопки, подписи полей, сообщения форм) сюда не кладём —
им место в `messages/ru.json`.
