# Сайт агентства SEO Secrets

Сайт переезжает с Tilda на собственный код. Полный план — `docs/ROADMAP.md`,
прочитай его перед первой задачей в новой сессии. Сейчас идёт **этап 2–3**.

## Как устроен проект

- **Next.js 16 (App Router) + TypeScript + Tailwind 4**, деплой на Vercel.
- Локализация через **next-intl**. Русский — язык по умолчанию, **без префикса в URL**.
- Маршрутизация в `src/proxy.ts` (в Next.js 16 это бывший `middleware.ts`).
- Строки интерфейса — `messages/ru.json`. Длинные тексты страниц — `content/`.

```
src/app/[locale]/   страницы
src/i18n/           конфигурация локалей
src/lib/            утилиты
src/proxy.ts        локализованная маршрутизация
messages/           строки интерфейса
content/            тексты страниц и блога
docs/ROADMAP.md     план проекта
```

## Правила, которые нельзя нарушать

1. **URL не меняются.** Адреса страниц перенесены с Tilda один в один — это условие
   сохранения позиций. Если адрес всё же меняется, в тот же коммит добавляется 301-редирект
   в `next.config.ts`. Не «потом», а сразу.

2. **Русский без префикса.** `/uslugi`, а не `/ru/uslugi`. В `routing.ts` пока одна локаль.
   Казахский добавляется отдельной задачей, когда появятся переводы, — не «на будущее».

3. **Цвета и шрифты только из токенов** в `src/app/globals.css`. В компонентах —
   `bg-surface`, `text-muted`, `text-accent`. Произвольные значения вида `bg-[#0f6b4c]`
   и `text-[15px]` не использовать: из-за них дизайн расползается за пару недель.

4. **Ссылки внутри сайта — из `@/i18n/navigation`**, а не из `next/link`. Иначе при
   добавлении второго языка префиксы придётся расставлять руками по всему проекту.

5. **Индексацию тестового домена не открывать.** Флаг `NEXT_PUBLIC_ALLOW_INDEXING`
   включается один раз, на этапе 8, только на боевом домене.

6. **Тексты не переписывать по своей инициативе.** Контент переносится с Tilda как есть.
   Переписывание — отдельная задача после стабилизации позиций.

7. **Секреты только в переменных окружения.** Ключи, токены и вебхуки не попадают
   в репозиторий. Новую переменную добавил — сразу впиши в `.env.example`.

## Тон текстов

Пишем от лица агентства, которое понимает в SEO: конкретика вместо обещаний, цифры вместо
превосходных степеней. Не «лучшее агентство с индивидуальным подходом», а «выводим
коммерческие страницы в топ-10 за 4–6 месяцев, отчитываемся ежемесячно». Без восклицательных
знаков, без «мы предлагаем широкий спектр услуг».

## Перед коммитом

```bash
npm run build   # обязательно: TypeScript и сборка
npm run lint
```

Если сборка падает — чинить, а не обходить. Отключать проверки типов в конфиге нельзя.
