# Сайт агентства SEO Secrets

Новый сайт агентства на Next.js. Переезд с Tilda, правки вносятся через диалог с ИИ.

- **План проекта:** [`docs/ROADMAP.md`](docs/ROADMAP.md)
- **Правила для ИИ-сессий:** [`CLAUDE.md`](CLAUDE.md)
- **Текущий этап:** 2–3 — инфраструктура и дизайн-система

## Как вносить правки

Код руками править не нужно. Цикл такой:

1. Открыть [claude.ai/code](https://claude.ai/code), выбрать этот репозиторий.
2. Написать задачу обычным текстом.
3. Дождаться pull request — Vercel приложит к нему ссылку на превью с правками.
4. Посмотреть, уточнить словами, нажать Merge.

Изменения уезжают на тестовый домен автоматически. Откат — кнопкой Rollback в Vercel.

## Локальный запуск

Нужен, только если хочется посмотреть сайт без деплоя.

```bash
npm install
cp .env.example .env.local
npm run dev          # http://localhost:3000
```

```bash
npm run build        # сборка и проверка типов — обязательна перед коммитом
npm run lint
```

## Что важно знать

- Русский отдаётся по корню без префикса (`/uslugi`), казахский добавится позже на `/kk/`.
- Индексация закрыта, пока `NEXT_PUBLIC_ALLOW_INDEXING` не равна `true`.
  Открывается один раз — на боевом домене, на последнем этапе.
- Маршрутизация лежит в `src/proxy.ts`: в Next.js 16 это бывший `middleware.ts`.
