# Снимок текущего сайта

Здесь лежит копия seo-secrets.kz на Tilda: разметка, стили и скриншоты.

Зачем: у среды агента нет выхода в интернет, и открыть сайт он не может.
Без этой папки каждый блок пришлось бы собирать по скриншоту, присланному
руками, — то есть на глаз. По разметке видны фактические размеры, цвета
и шрифты, и блок собирается сразу правильно.

- `html/` — разметка страниц после отработки скриптов
- `css/` — подключённые таблицы стилей
- `screens/` — скриншоты страниц целиком, ширина 1466

Обновляется workflow «Снимок сайта» (`.github/workflows/snapshot-site.yml`).
Список страниц — `pages.json`.

**Папка временная.** После переезда и снятия Tilda её нужно удалить вместе
с workflow и `scripts/snapshot-site.mjs`.
